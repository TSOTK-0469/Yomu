# Yomu

Yomu 是一个专注于本地图片的 Android 阅读器。

## 已实现

- 通过 Android 系统目录选择器挂载多个文件夹，访问权限可跨重启保留
- 挂载时可选择非递归或递归模式，并显示实时扫描进度
- 内置子目录选择器，可以进入并单独挂载名称以 `.` 开头的隐藏文件夹
- 每个“直接包含图片”的目录自动成为一册
- Room 持久保存画册摘要和已排序的完整图片索引：启动和日常打开画册均不重新扫描
- 从 0.2.0 升级后，旧画册首次打开时自动补全一次图片索引
- 按挂载源独立刷新，刷新失败时保留上一次完整索引
- 重复打开已索引画册时不再显示阻塞弹窗；仅旧数据首次补索引时显示明确、可取消的提示
- “全部画册”和自建书架；画册可同时加入多个书架
- 书架支持创建、重命名、删除和自定义封面
- 画册可设置仅在 Yomu 内生效的显示名称，刷新后仍会保留，也可恢复来源名称
- 画册长按可重命名、管理书架、设置封面或隐藏；隐藏画册可在挂载管理中恢复
- JPG、PNG、WebP、GIF、BMP、HEIC/HEIF、AVIF 文件识别（实际解码能力取决于 Android 系统版本）
- 文件名自然排序，例如 `1.jpg`、`2.jpg`、`10.jpg`
- 舒适、标准、紧凑三档自适应书架布局，可在设置中即时切换
- 全屏挂载管理显示来源路径、授权状态、扫描模式、画册数量和上次成功刷新时间
- 浅纸黄色与白色的阅读友好界面，并随系统切换暖色深色主题
- 分页阅读：滑动翻页、左右点按翻页、双击缩放、双指缩放和拖动
- 长图阅读：无缝纵向连续滚动
- 在设置的“阅读”分组统一选择分页/长图及左到右/右到左方向，阅读页可直接进入设置
- 分页缩放围绕双指中点或双击位置，放大后 1:1 跟手拖动并支持惯性
- 搜索、书架命名和画册重命名统一支持光标及选区控制柄边缘持续滚动
- 画册封面使用轻微圆角，标题区域保持完整
- 沉浸式系统栏、页码滑杆、自动记忆每册进度
- 阅读位置跟随最后阅读的图片；该图片消失时回到首张图片
- 动态内存 LRU 与 256 MiB 封面缩略图磁盘缓存
- 不申请“管理所有文件”权限，也不访问网络

## 打开与构建

1. 使用支持 Android Gradle Plugin 9.3 的 Android Studio 打开项目。
2. 安装 Android SDK 37.1，并让 Gradle 使用 JDK 17。
3. 等待 Gradle 同步后，运行 `app` 配置；或执行 `gradlew.bat assembleDebug`。

调试 APK 会生成在 `app/build/outputs/apk/debug/app-debug.apk`。当前版本为 0.3.3。

## 关于隐藏目录

扫描器不会过滤点号目录。如果系统选择器不显示某个隐藏目录，请先授权它的可见父目录，再在 Yomu 的子目录选择器中进入并挂载 `.hidden` 目录。

Android 11 及以上不允许第三方应用通过目录选择器授权内部存储根目录、下载目录根、`Android/data` 或 `Android/obb`，这是系统限制。请选择它们下面允许访问的具体目录，或使用其他位置。

## 项目结构

- `data/LibraryRepository.kt`：目录授权、挂载/刷新扫描、书架操作与索引协调
- `data/db/`：Room 数据库、画册索引与多书架关系
- `data/NaturalOrder.kt`：图片页码自然排序
- `ui/LibraryScreen.kt`：书架侧栏、搜索、封面、挂载管理与设置
- `ui/ReaderScreen.kt`：分页与长图阅读器
- `ui/ImageLoader.kt`：本地 URI 解码、降采样、内存 LRU 和封面磁盘缓存
