# Yomu 0.3.1

Yomu 0.3.1 improves repeat Album opening and reorganizes the local library experience.

## Highlights

- Indexed Albums open without the obsolete sorting blocker.
- Slow opens use non-blocking feedback on the selected Album card after 300 ms.
- Legacy Albums show an explicit one-time indexing dialog only when their image index is absent.
- Albums can use a local display name without renaming the source folder.
- Search and natural sorting recognize both display names and source names.
- The Bookshelf drawer has clearer grouping and fixed management destinations.
- Mount Source management is now full screen with access state, scan mode, counts, path copying, refresh time, and grouped Hidden Albums.
- Settings adds Comfortable, Standard, and Compact adaptive Album grids plus disk-cache controls.
- The library uses a paper-yellow and white light palette with a warm charcoal dark theme.
- Room schema v3 preserves existing library data without forcing an upgrade scan.
- Album cover corners no longer hide information near the image edges.
- Long Album names keep the rename cursor visible while editing.
- The new paper-style Yomu launcher icon is included at all Android densities.

## Installation note

This APK is debug-signed. If Android reports a signature conflict with a differently signed build, uninstall that build before installing 0.3.1. Uninstalling clears app-managed library metadata, so record any important setup first.
