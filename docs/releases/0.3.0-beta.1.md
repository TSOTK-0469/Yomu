# Yomu 0.3.0-beta.1

This beta focuses on faster repeat Album opening and a clearer library experience.

## Highlights

- Indexed Albums no longer show the obsolete sorting blocker when opened.
- Slow opens use non-blocking feedback on the selected Album card after 300 ms.
- Legacy Albums show an explicit one-time indexing dialog only when their image index is absent.
- Albums can use a local display name without renaming the source folder.
- The Bookshelf drawer and full-screen Mount Source manager have a clearer hierarchy.
- Settings adds Comfortable, Standard, and Compact adaptive Album grids.
- The library uses a paper-yellow and white light palette with a warm charcoal dark theme.
- Room schema v3 preserves existing library data without forcing an upgrade scan.
- Album cover corners no longer hide information near the image edges.
- Long Album names keep the rename cursor visible while editing.
- The supplied paper-style Yomu artwork is now used as the launcher icon.

This build is debug-signed for beta testing. Android may require uninstalling a differently signed build before installation.
