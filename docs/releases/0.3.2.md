# Yomu 0.3.2

Yomu 0.3.2 polishes touch editing and Reader controls.

## Highlights

- Long Album display names now scroll horizontally while dragging the insertion cursor or either text-selection boundary near an input edge.
- Zoomed images retain direct 1:1 dragging and continue moving with velocity-based inertia after a fast release.
- A new touch immediately interrupts image inertia.
- Zoomed movement stops at the bitmap's real fitted bounds without turning the page or exposing avoidable black space.
- The Reader progress control now uses a 3 dp rounded track and a 14 dp circular thumb while retaining its existing seek behavior and touch target.

## Installation note

This APK is debug-signed. If Android reports a signature conflict with a differently signed build, uninstall that build before installing 0.3.2. Uninstalling clears app-managed library metadata, so record any important setup first.
