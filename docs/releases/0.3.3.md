# Yomu 0.3.3

本地开发版本，尚未发布到 GitHub。

## 改动

- 搜索、书架新建/重命名和画册重命名统一支持光标与选区控制柄的边缘持续滚动；越靠边越快，松手或移回内部停止。
- 修复分页图片放大后拖动慢于手指、松手没有惯性的问题；再次触摸立即停止惯性。
- 双指围绕两指中点缩放并可同时平移；双击围绕点击位置放大。移动仍受实际图片边界约束。
- 画册封面增加 8 dp 圆角，文字区域不做圆角裁剪。
- 分页/长图与左右阅读方向移到设置页的“阅读”分组，阅读页提供设置入口。切换保留当前图片并重置缩放；长图模式禁用方向选项但保留选择。

## 数据与兼容性

- `applicationId`：`cn.yomu.reader`；`versionCode`：7；`versionName`：0.3.3。
- 不修改数据库结构、挂载语义、画册命名和已有阅读偏好的保存位置。
- 长图模式不新增缩放。
- 调试安装包仍使用 debug 签名。

## 实现与验证说明

- 原触控回归复现：2.5 倍放大时手指移动 60 px，图片只移动 24 px，且释放后位置不变。将触控接收放到缩放绘制层外后，跟手和惯性测试通过。
- 原边缘滚动回归复现：光标停在左边缘 800 ms，字符位置维持 62 不变。新增按帧驱动后持续滚动，并保留现有输入法、选择和剪贴板交互。
- 持续滚动适配器依赖当前锁定的 Compose 1.11.4 内部拖动状态；升级 Compose 时必须运行控制柄触控回归，不可只做编译验证。
- 触控测试使用本地 Robolectric：图片手势与设置使用 API 35，文本控制柄使用 API 27 原生图形模式，避开本地测试环境不支持的平台放大镜窗口。
- 本次没有连接实体手机；设备输入法、平台放大镜与实际手感仍需真机验收。
