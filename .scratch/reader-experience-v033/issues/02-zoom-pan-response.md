# 放大图片移动手感

Type: bug
Status: resolved

用户反馈放大后图片移动问题仍未解决，并进一步说明“目前这个滑动的功能根本没有成功实现”。

## Comments

- 用户已确认：图片很慢地移动，速度比手指慢，而且离开后没有惯性。
- 将接触期间 1:1 跟随与松手后惯性作为两个独立验收项，不默认归因为速度或惯性参数。
- 上轮惯性改动不能代替本轮症状复现；确定精确症状后建立可失败的验证闭环。

## 复现记录

运行 `.scratch/reader-experience-v033/verify.ps1`（本地 Robolectric/Compose 触控，Android API 35）：

- `zoomedDragTracksFingerInScreenPixels`：2.5 倍时手指移动 60 px，图片只移动 24 px，失败。
- `releasingFastDragContinuesMoving`：释放前后 x 均为 15.999985，失败。
- 同一真实分页图片组件使用方形图片且远离边界，无加载和翻页干扰。

依次验证：缩放层内的触摸坐标、手势更新与惯性取消的时序、边界限制。先只移动触摸检测与绘制缩放的层级，再重跑同一组手势。

## Answer

已确认原因是触控接收位于缩放绘制层内，触摸位移和释放速度被变换。将接收器移至缩放层外，保留现有惯性算法；仅此层级调整即使 60 px 跟手测试和释放后继续运动测试通过。双指手势不误触发单指惯性，再次触摸可停止惯性。
