# 所有文本输入框边缘自动滚动

Type: bug
Status: resolved

用户反馈书架重命名仍然没有边缘自动滚动，要求所有应用内文本输入框支持对应功能。

## Comments

- 用户确认覆盖搜索、书架新建/重命名、画册重命名；拖动插入光标及任一选区控制柄至左右边缘应持续滚动，越靠边越快，松手或离开边缘停止，保留键盘弹出规则。
- 不以组件替换或初始化光标测试通过作为边缘滚动验收依据。

## Answer

统一搜索、书架命名和画册重命名的输入组件；在保留原生输入法、剪贴板与控制柄的基础上，使用按帧驱动的边缘滚动。真实控制柄测试覆盖光标左右边缘、选区起点/终点、松手停止和移入内部停止。原始静止边缘复现为 800 ms 后位置 62 → 62，修复后通过。适配层明确绑定 Compose 1.11.4；升级时必须重跑触控测试。
