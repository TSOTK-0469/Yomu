# Refine the Reader progress slider

Type: enhancement
Status: resolved

The default Material slider track is visually heavy and its vertical-bar thumb does not match the desired Reader controls.

## Comments

- Use a 3 dp rounded track and a 14 dp circular thumb.
- Retain theme colors, seek behavior, and a comfortable touch target.

## Answer

Replaced the default visible track and vertical thumb with a 3 dp rounded theme-colored track and a 14 dp circular thumb while retaining the Slider's existing interaction and seeking semantics.
